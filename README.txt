راهنمای استفاده

1. همه فایل ها را داخل GitHub repo آپلود کن.
2. Cloudflare Pages خودش deploy می کند.
3. سایت اصلی:
   https://amirhosssein.cam
4. پنل ادمین:
   https://amirhosssein.cam/#/admin

رمز پیش فرض پنل:
123456

تغییر رمز:
داخل pages.js مقدار adminPassword را عوض کن.

ساخت لینک:
از پنل ادمین لینک بساز.
لینک ها در همان مرورگر ذخیره می شوند.
برای دائمی شدن، روی دکمه "کد pages.js" بزن و کد را داخل pages.js کپی کن.

تغییر hello:
داخل pages.js مقدار routeWord را عوض کن.

مثال:
routeWord: "hello"
لینک می شود:
#/hello/Bazi1

routeWord: "game"
لینک می شود:
#/game/Bazi1

تغییر پریویو:
داخل index.html این قسمت ها را تغییر بده:
og:title
og:description
twitter:title
twitter:description

تغییر عکس پریویو:
فایل preview.jpg را با عکس خودت جایگزین کن.
سایز پیشنهادی: 1200x630

تغییر لوگوی مرورگر:
فایل favicon.png را با لوگوی خودت جایگزین کن.
سایز پیشنهادی: 512x512
